Implementation & Code Snippet

To ensure idempotency in our data transformation layer, we implemented an upsert logic within the ETL pipeline. Below is an abstracted representation of the core data merging function.

import pandas as pd
from sqlalchemy import create_engine

def upsert_financial_data(df_new, table_name, engine):
    """
    Upserts new financial records into the target database.
    Ensures no duplicate transaction IDs are recorded.
    """
    # Create temporary table
    df_new.to_sql('temp_table', engine, if_exists='replace', index=False)
    
    # SQL query for conflict resolution (PostgreSQL specific)
    upsert_query = f"""
    INSERT INTO {table_name}
    SELECT * FROM temp_table
    ON CONFLICT (transaction_id) 
    DO UPDATE SET 
        status = EXCLUDED.status,
        updated_at = CURRENT_TIMESTAMP;
    """
    with engine.begin() as conn:
        conn.execute(upsert_query)
