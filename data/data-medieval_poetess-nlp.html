CH01 - Linguistic Feature Extraction (NLP)

To spot themes and emotions, we employ Natural Language Processing techniques. The translation pipeline is used to translate French text into English, making it easier to apply emotion analysis models that work with English text. The translation model used here is `Helsinki-NLP/opus-mt-fr-en`, which is specifically trained for machine translation between French and English.

The emotion classification model detects the emotion conveyed in each translated line of text. It assigns each line an emotion label and a confidence score. This is a supervised machine learning model applied to textual data, trained to classify emotions like joy, sadness, anger, etc.

Categorical encoding is applied to convert the emotional labels into numerical codes. This transformation allows the emotional labels to be used effectively in visualizations, where color and size can represent these numerical values.

Translation Classification Tokenization

From raw text to DataFrame

This project uses Natural Language Processing (NLP)

  • Linguistic Translation (NMT): The script utilizes the Helsinki-NLP neural machine translation model to bridge the gap between medieval syntax and modern English, ensuring the sentiment engine receives data it was specifically trained to understand.
  • Semantic Vectorization: Using a DistilRoBERTa architecture, the code transforms translated sentences into high-dimensional vectors that capture the contextual meaning and relationship between words.
  • Emotion Classification: The NLP engine calculates the mathematical probability of seven distinct emotions (including Joy, Sadness, Anger), selecting the label with the highest confidence score for each line.
  • Nested Result Extraction The logic includes a recursive check (isinstance) to safely navigate the model's nested list outputs, extracting the raw label and score while preventing script crashes from unexpected data shapes.
  • Nested Result Extraction Processed results are aggregated into a pandas DataFrame.

CH02 - Comparative Stylometry (PCA)

To compare unique styles, the data is projected into a multidimensional space. While the current dashboard focuses on thematic axes, the underlying logic utilizes Principal Component Analysis (PCA) principles to reduce complex linguistic variances into visible patterns, highlighting what distinguishes each poetess’s "voice."

TfidfVectorizer PCA KMeans

Here, with TF-IDF (Term Frequency-Inverse Document Frequency), I prioritize words that are uniquely characteristic of a poetess. PCA (Principal Component Analysis) then compresses hundreds of linguistic features into two axes, allowing us to see the "gravitational pull" of different styles.

Unlike a static cluster, the Connected Scatterplot treats the text as a sequence. By connecting dots (verses) in order, we visualize the tonal journey of a poem.

By applying K-Means Clustering, we allow the data to "speak" without human bias.

  • We can visually identify if Anna Komnene's historical prose shares a structural "DNA" with Wallada’s independent verses, despite their different centuries.
  • Sudden "spikes" in the line represent thematic ruptures—moments where a poetess shifts from a neutral narrative to a highly emotional or political outburst.
  • When the algorithm groups Hildegard and Marie de France together in a specific cluster, it scientifically validates the shared use of natural metaphors.

CH03 - Unsupervised Clustering (K-Means)

To reveal connections across time and space, we utilize the Scikit-learn implementation of the K-Means algorithm. By analyzing the proximity of verses within the thematic vector space, the system automatically groups segments into four academic clusters. This reveals structural similarities in storytelling that transcend geographical and linguistic barriers.

Translation Classification Tokenization

This project uses >Natural Language Processing (NLP)

  • Vectorization: The raw text is converted into a numerical matrix. Each word becomes a dimension, creating a "thematic space" where similar verses are mathematically close to each other.
  • Clustering & Projection: The K-Means algorithm assigns each verse to one of four clusters. PCA then flattens this multi-dimensional space into pca1 and pca2 coordinates so they can be plotted on a standard X/Y axis

Why 4 Clusters?

Cluster 1: Nature/Love

Focuses on natural imagery (the hazel and the honeysuckle) and romantic longing, frequently bridging the works of Marie de France and Wallada

Cluster 2: Power/History

Groups together formal rhetoric, historical accounts, and lineage, a space dominated by Anna Komnene’s Alexiad

Cluster 3: Spirituality

Identifies language of divine revelation and cosmic order, specifically isolating the unique theological vocabulary of Hildegard von Bingen

Cluster 4: Loss/Memory

A "cross-temporal" cluster where the melancholy of lost love or political displacement creates a mathematical bond between verses from different continents

In unsupervised learning, selecting the number of clusters (the $k$ in K-Means) is an intentional choice to balance granularity with clarity. For this project, four clusters were chosen to mirror the four distinct voices of the poetesses while testing if their themes would actually merge or stay isolated -

Thematic vs. Stylometric Analysis

Analysis Type Focus DANKI Objective
STYLOMETRY (PCA) Linguistic habits, syntax, and rhythmic patterns. To isolate and celebrate the unique genius of the individual creator.
CLUSTERING (K-MEANS) Semantic meaning, shared vocabulary, and topics. To connect voices across time through universal human archetypes.

While Stylometry verifies the inimitable signature of each poetess, K-Means Clustering reveals the invisible threads that bind them together, proving that shared emotional landscapes transcend geographical and linguistic borders.
