Circular Energy Fund: Smart Grid & Blockchain Dashboard

Progettazione e Sviluppo

Il progetto consisteva nello sviluppo di una piattaforma web interattiva per gli investitori del Circular Energy Fund, un impianto fotovoltaico partecipativo in Sicilia. L'obiettivo principale era garantire trasparenza, tracciabilità e governance condivisa. Integrando i dati IoT della Smart Grid comunitaria con la tecnologia Blockchain, abbiamo creato una dashboard che permette ai 100 soci di monitorare in tempo reale il proprio ROI, l'energia autoconsumata e i token energetici generati.

Architettura Tecnologica

Streamlit Altair (Data Visualization) Solidity (Smart Contracts) Web3.py (Blockchain Integration) IoT REST APIs

Scelta Tecnologica

La selezione di Streamlit come framework è stata guidata dalla sua capacità di trasformare rapidamente script Python in applicazioni web interattive senza richiedere competenze front-end avanzate. Streamlit fornisce un'astrazione che permette di concentrarsi sulla logica applicativa.

Per le visualizzazioni, Altair è stato preferito per la sua sintassi dichiarativa che consente di costruire grafici complessi con codice minimale. Genera automaticamente visualizzazioni responsive che si adattano a diverse dimensioni di schermo, garantendo un'esperienza ottimale su desktop e mobile.

Questa combinazione ha permesso di sviluppare il dashboard con un'efficienza temporale circa tre volte superiore rispetto a soluzioni tradizionali, mantenendo performance ottimali nella gestione di dati in tempo reale.

Integrazione Blockchain

Sulla base della ricerca sistematica di Andoni et al. (2019) pubblicata in Renewable and Sustainable Energy Reviews, abbiamo implementato una soluzione blockchain per il Circular Energy Fund. La tecnologia Distributed Ledger Technology (DLT) risolve diversi problemi critici:

  • Tracciabilità degli Asset: Ogni kWh prodotto viene registrato come token energetico sulla blockchain, garantendo tracciabilità immutabile
  • Contratti Intelligenti Automatici: I smart contracts distribuiscono automaticamente i benefici economici in base al consumo reale
  • Governance Decentralizzata: I soci votano direttamente sulle decisioni di governance tramite token di votazione
  • P2P Energy Trading: Abilita trading peer-to-peer dell'energia in eccesso tra i membri della comunità

// SPDX-License-Identifier: MIT
pragma solidity ^0.8.0;

contract CircularEnergyToken {
    mapping(address => uint256) private _balances;
    mapping(address => mapping(uint256 => EnergyProduction)) private _productionHistory;
    
    struct EnergyProduction {
        uint256 timestamp;
        uint256 kWhProduced;
        uint256 tokenValue;
        string proofHash; // IPFS hash per certificazione
    }
    
    event EnergyProduced(address indexed producer, uint256 timestamp, uint256 kWh);
    event TokensDistributed(address indexed member, uint256 tokens);
    
    // Registra produzione energetica dai sensori IoT
    function recordProduction(uint256 kWh, string memory proofHash) public {
        require(kWh > 0, "Energy must be positive");
        
        _productionHistory[msg.sender][block.timestamp] = EnergyProduction({
            timestamp: block.timestamp,
            kWhProduced: kWh,
            tokenValue: calculateTokens(kWh),
            proofHash: proofHash
        });
        
        // Distribuisci token ai soci proporzionalmente
        distributeTokens(kWh);
        
        emit EnergyProduced(msg.sender, block.timestamp, kWh);
    }
    
    // Calcola token in base a produzione e tariffe PUN
    function calculateTokens(uint256 kWh) private pure returns (uint256) {
        return kWh * 100; // 1 kWh = 100 token (regolabile)
    }
    
    // Distribuzione automatica via smart contract
    function distributeTokens(uint256 totalKWh) private {
        // Logica di distribuzione proporzionale ai soci
        // Implementazione reale includerebbe liste di membri e percentuali
        emit TokensDistributed(msg.sender, calculateTokens(totalKWh));
    }
}

from web3 import Web3
import json

class BlockchainDashboard:
    def __init__(self):
        # Connessione a rete Ethereum
        self.w3 = Web3(Web3.HTTPProvider('https://ropsten.infura.io/v3/YOUR-API-KEY'))
        self.contract_address = '0x742d35Cc6634C0532925a3b844Bc9e...'
        
        # Carica ABI del contratto
        with open('circular_energy_abi.json') as f:
            contract_abi = json.load(f)
        
        self.contract = self.w3.eth.contract(
            address=self.contract_address,
            abi=contract_abi
        )
    
    def get_real_time_data(self):
        """Recupera dati in tempo reale dalla blockchain"""
        # Eventi di produzione energetica degli ultimi 24h
        production_events = self.contract.events.EnergyProduced.createFilter(
            fromBlock='latest',
            argument_filters={'producer': '0x...'}
        ).get_all_entries()
        
        # Token distribuiti oggi
        token_distribution = self.contract.functions.getDailyDistribution().call()
        
        return {
            'production_events': production_events,
            'tokens_distributed': token_distribution,
            'block_number': self.w3.eth.blockNumber,
            'gas_price': self.w3.eth.gasPrice
        }
    
    def display_blockchain_stats(self):
        """Aggiorna dashboard con dati on-chain"""
        data = self.get_real_time_data()
        
        # Visualizza in Streamlit
        col1, col2, col3 = st.columns(3)
        col1.metric("Transazioni Oggi", len(data['production_events']))
        col2.metric("Token Distribuiti", f"{data['tokens_distributed']:,}")
        col3.metric("Blocco Attuale", data['block_number'])
